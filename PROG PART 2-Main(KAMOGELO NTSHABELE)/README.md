# Registration
Login and Registration System
This is a Java application that you can use on your computer. It helps to manage users in a way. The application checks everything you enter to make sure it is correct. It also has tests to make sure everything works properly.

Here are the features of the Login and Registration System.
•	User Registration: when you register the system will ask for your name, a username, a password and your phone number.
•	The system will check your username to make sure it has an underscore in it and is not too long.
•	It will also check your password to make sure it is long enough. Has a capital letter, a number and a special character.
•	Your phone number needs to be, in the African format, which starts with +27.
•	Secure Login: when you try to log in the system will check your details to make sure they are correct.
•	Unit Testing: the system has tests to make sure everything works correctly. These tests are done using JUnit 5.
•	The Login and Registration System checks all the parts of the application to make sure they are working as they should.
